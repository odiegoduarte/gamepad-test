# Teste de Gamepad

Aplicação web para testar gamepads no navegador usando a HTML5 Gamepad API. Exibe em tempo real o estado dos analógicos, botões e gatilhos de cada controle conectado.

https://odiegoduarte.github.io/gamepad-test/

## Como usar

1. Abra a URL acima.
2. Conecte um gamepad via USB ou Bluetooth.
3. Pressione qualquer botão para o navegador expor o controle.
4. Mova os analógicos e pressione os botões para acompanhar os valores em tempo real.
